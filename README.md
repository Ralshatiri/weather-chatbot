# Weather Chatbot

An AI-powered weather forecasting chatbot built using the **Google Agent Development Kit (ADK)** and **Gemini**. The chatbot allows users to request weather forecasts for supported cities in Saudi Arabia through a simple conversational interface.

It retrieves existing forecasts from the database when available. If the requested forecast is missing, the chatbot communicates with the prediction API to generate a new forecast and returns the result to the user.

The application is integrated with **Open WebUI** and packaged using **Docker** for easier deployment and management.
